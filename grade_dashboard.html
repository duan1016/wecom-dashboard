二、口径说明
a. 家用 SAB 等级口径
取 “家用-零售规模(小B口径)” = 家用全品牌美云销 + 工程安装金额，对照家用零售分级标准确定 S/A/B 等级。
b. 日度等级
取累计达成金额与等级要求达成规模对比，并 按天数折算（即把年度等级门槛按当年已过天数等比例折算为当期应达规模，再与实际累计达成比较）。
c. 季度等级
每季度初取 上季度末等级 作为本季度等级。
d. 年度等级
取 上年年末动态等级 作为本年冻结年度等级。
三、等级预警规则
⚠ 家用低于整体
当商户的 家用 等级（S>A>B>C>D>未定级）低于其整体等级时，系统自动标黄预警（家中等级不参与预警判断）：
  • 等级矩阵中，低于整体的单元格以 黄底 标记，并在“预警”列文字说明；
  • 商户明细中，冻结/日度的家用各设独立列，低于整体时同样标黄，并在“预警”列汇总原因。
家中等级已全表移除
按最新口径，看板所有等级展示仅保留 整体 / 家用 两列，家中等级不再展示、也不再参与预警统计。
四、升级差额口径
怎么算的
以商户当前 日度动态等级·家用 为起点，升一级作为目标等级（C→B、B→A、A→S、D/未定级→C；S 级已是最高，仍按 S 门槛考核），取家用零售规模年度门槛，按 当年已过天数折算 到截至日得到应达金额：
  • 目标金额 = 目标等级家用门槛 ×（截至 2026-09-30 的已过天数 273 / 全年 365 天 = 0.7479）；
  • 升级差额 = 目标金额 − 已达成金额；正数 = 还差这么多，负数 = 已超额达成；
  • 单元格形如「→B +12.3万」：箭头后为目标等级，数值为差额；鼠标悬停可看目标金额与已达成金额。

五、环比上周口径
环比上周情况（持续 / 改善 / 恶化）
以 商户编码 为唯一键，将本周等级与上周同期等级逐户比对，“整体”口径：等级升高记为 改善，等级降低记为 恶化，等级不变记为 持续；上周无该商户记录记为 新增。
环比上周变化（预警数量）
“维度概览”表中，取该城市 本周预警商户数 − 上周同期预警商户数：数值升高以红色 ▲ 标注（预警面扩大），下降以绿色 ▼ 标注（预警面收窄），持平显示“持平”。
六、城市归属口径
三级城市解析
以 商户编码 为唯一键，按序取值：① 商户基础信息表「城市」列（O 列） → ② 未匹配城市商户清单回填的「城市」列 → ③ 无值记为空。不按商户名称做模糊猜测，保证唯一键严格匹配。
未关联城市商户的处理
取不到城市的商户（多为京东、淘宝等全国性电商 / KA / 跨区户）不进入城市维度：不参与 KPI 卡片、维度概览、日度汇总表与等级矩阵的统计。仅在「商户明细」页勾选 “明细含未关联城市商户” 时可单独查看，城市列显示为 —。
七、日度 S/A/B 环比与导出口径
S/A/B 客户数
统计各周快照中 日度动态等级·整体 为 S / A / B 的商户户数，再按城市归属聚合。
环比上周变化量
该城市 本周户数 − 上周同期户数。S/A/B 是客户结构向上集中的正向指标，因此 增加以绿色 ▲ 标注、减少以红色 ▼ 标注、持平显示“持平”——与“预警数”的配色语义相反（预警数增加才是坏事）。
导出表格 / 导出图片
「日度动态汇总」顶部两个按钮：导出表格 (CSV) 含城市明细与全区域合计行，Excel 可直接打开；导出图片 (PNG) 为表格快照，可直接贴进周报或微信群。两者都与当前「城市」筛选联动——筛选某城市后导出，即只含该城市数据。
时间粒度
分级明细导出为 每周一个日度快照（每份 Excel 内每户仅一条记录），因此环比均为本周与上周同期两点对比；补充历史周快照后，相关统计会自动按多期延展。
