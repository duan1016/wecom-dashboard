📌 看板说明（结构确认版）
1. 监控机型与白名单限额：来自《监控机型.xlsx》，为真实配置；订单、安装、提货、客户明细等其余数据均为真实数据，仅用于确认看板结构；
2. 顶部机型筛选：选中机型后，四项指标按该机型口径计算 —— 授权客户数量（该机型已授权客户数）、样机下单客户数量（样机下单 > 0 的客户数）、订单客户数量（订单 > 0 的客户数）、安装客户数量（安装 > 0 的客户数）；「全部机型」= 任一监控机型满足即计入；
3. 常驻核心机型卡片（KFR-35GW/T3-、KFR-72LW/J2、KFR-35GW/J2）：指标口径与西安看板一致 —— 限额达标率 = 授权客户数 ÷ 白名单限额；样机下单率 = 样机下单>0 客户数 授权客户数；实机下单率 = 订单>0 客户数 ÷ 授权客户数；动销率 = 已安装客户数 ÷ 授权客户数；
4. 监控机型清单：安装总量 = 该机型安装数量合计；动销客户数量 = 已授权且安装 > 0 的客户数，动销率 = 动销客户数 ÷ 授权客户数；样机下单客户数量 = 已授权且样机下单 > 0 的客户数，样机下单占比 = 样机下单客户数 ÷ 授权客户数；订单客户数量 = 已授权且订单 > 0 的客户数，订单客户占比 = 订单客户数 ÷ 授权客户数；表头点击可排序（再点切换升/降序）；每行「导出跟进图片」按钮可将该机型 0 安装 / 样机 0 下单 / 0 订单 的已授权客户清单导出为 PNG 图片，便于转发跟进；
5. 明细表：城市 / 区县 / 客户编码 / 客户名称四个下拉筛选（区县选项随所选城市联动，选中城市后看板所有数据同步筛选，多条件之间为「且」的关系），配合搜索框（支持产品型号 / 城市 / 区县 / 客户编码 / 客户名称关键字）共同过滤，选中下拉后输入关键字可快速定位单个客户；表头点击可排序（再点切换升/降序）；数量列为当前口径机型下的合计，0 值置灰显示；明细表右上方「导出图片」按钮可一键将当前筛选结果导出为 PNG 图片；
